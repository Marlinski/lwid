Notebook help

How this runs

Python executes entirely in your browser via Pyodide (a WebAssembly build of CPython) — no server ever sees your code or its output. The first run downloads the Python runtime (roughly 10–20 MB); after that, cells run instantly. numpy, pandas and matplotlib install themselves automatically the first time you import them.

Keyboard shortcuts

Shift+EnterRun the cell, then move to (or create) the next
Ctrl/Cmd+EnterRun the cell in place
Alt+EnterRun the cell, then insert a new one below
TabIndent

Hover a cell for its + (insert code / insert markdown) and × (delete) controls.

Sharing

Anyone with this link can run cells — results are saved to the project's encrypted store and shown to the next person who opens it, whether or not they can edit. Only an edit link can change the notebook's actual cells; use Save .ipynb to publish those changes as a new version.
